# Taxi Marketplace Metrics Analysis

Анализ эффективности маркетплейса такси на данных о поездках с 10-минутной разбивкой. В работе рассчитаны ключевые продуктовые метрики маркетплейса: AR (acceptance rate), SH (supply hours), TPH (trips per hour), MPH (money per hour) и Efficiency — доля времени, которое водитель тратит на перевозку пассажира. Отдельно исследовано, как метрики меняются в течение дня и в пиковые часы.

Дополнительно проведён корреляционный анализ: связь суржа с долей свободных водителей и связь времени поиска исполнителя с количеством свободных машин. На основе результатов сформулированы продуктовые рекомендации — по балансировке числа водителей на линии в течение дня и снижению простоев без роста времени ожидания для пассажиров.

## Метрики

| Метрика | Что показывает |
|---|---|
| AR | Доля принятых водителями предложений |
| SH | Суммарное время водителей на линии |
| TPH | Поездок на час работы водителя |
| MPH | Доход водителя на час работы |
| Efficiency | Доля времени, потраченного на перевозку |
